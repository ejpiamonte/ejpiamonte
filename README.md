### 🧱 Chapter 1: Infrastructure & Operations
I started close to the machines: monitoring, maintenance windows, access requests, runbooks, and SOPs. Working with tools like Dynatrace, SCOM, SCCM, Control-M and ServiceNow taught me what teams *actually* waste time on, and that became my roadmap for what to build.

### 🚀 Chapter 2: DTSS, the Dynatrace Self-Service Tool
My biggest build to date. Instead of waiting on tickets, teams get a web app to do it themselves.

- **Stack:** Python · HTML/CSS/JS · REST APIs · SQLite
- **Journey:** prototype → soft launch → full rollout (Nov 2026) 🎉
- **Extras:** a public reports API, with user and entity breakdowns, bot-vs-human classification, and multi-value filters
- **Lesson learned:** shipping is the easy part; adoption, feedback, and iteration are the real work
